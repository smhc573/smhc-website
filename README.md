# St Matthews Healthcare website: source

This is the `source` branch. It holds the content and build scripts for https://smhc.uk.com.
The live files are on the `main` branch, which the web host syncs.

See `CLAUDE.md` for how the site is laid out, how to make a change and the house rules.

In short: edit `source/data.py`, then run `python3 source/publish.py "what changed"`.
